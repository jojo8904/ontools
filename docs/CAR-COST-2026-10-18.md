## 계산식

- 구매: 계약 시 차량 납부액/부대비용 + 기간 납부액 + 만기 미상환 원금/정산액 + 별도 운영비. 현금 구매는 차량 대금을 초기 금액에 입력하고 할부 구매는 계약 시 납부액만 입력한다. 차량 총액/대출원금을 추가 합산하지 않는다.
- 리스/렌트: 초기 부대비용 + 소멸 선납금 + 보증금 + 기간 납부액 + 별도 운영비 + 만기 비용 − 보증금 반환/충당액.
- 반환 만기 비용: 반환·초과거리·손상·보증금 공제 예상액. 보유 자산은 0.
- 인수 만기 비용: 보증금 차감 전 인수대금 + 취득·이전·공제 등 별도 비용. 보증금을 반환/충당으로 한 번만 차감한다.
- 보증금 전액 정산 가정. 반환 공제액은 만기 비용에 입력해 실제 순환급 감소를 표현한다. 인수도 보증금 반환 후 전액 인수대금 납부 기준으로 표시하며 실제 차액 정산 방식과 다를 수 있음을 안내한다.
- 잔존가치 반영 총비용 = 보증금 정산 후 순현금지출 − 종료 시 매각 예상가. 계속 보유 시 자산 평가이며 현금 환급이 아니다. 매각대금을 다른 비용에서 미리 차감하지 않도록 안내한다.
- 월 환산 = 잔존가치 반영 총비용 / 기간. 실제 월 청구액과 구분.
- 월 납부액 × 개월 또는 직접 입력한 기간 납부총액 중 하나만 적용. 별도 보험·세금은 연 비용 × 개월/12, 월 유지비는 개월 곱. 포함 보험·세금의 숨겨진 값은 제외.

## 입력·안내

보험·자동차세·정비비의 포함/별도/미확인 선택 및 미확인 경고. 기간 차이는 비교 차단, 주행조건 차이는 경고. 반환/인수의 자산 차이 안내. 가입·결제·유료 API·견적 업로드·저장 없음. 모든 금액은 직접 입력하며 현행 세율·APR·감가·보험료·절세액을 하드코딩하지 않았다. 36개월/15,000km는 편집 가능한 비교 조건이며 상품 견적이 아니다. 비용 기본값 0은 무료가 아닌 미확인임을 안내한다.

## 후속 로컬 진단 (운영 반영 금지 상태 유지)

부모의 지시에 따라 원격 push/merge/배포 없이 구현을 보존했다. 운영 기준 커밋을 `git archive`로 `/workspace/ontools-baseline-bd66913`에 추출했으며 기존 checkout과 Git 참조는 변경하지 않았다. 설치된 node_modules를 재사용하고 worker 복사 스크립트를 실행한 뒤 baseline production build가 통과했다.

- 현재 checkout과 baseline의 `public/table-ocr.worker.js`, 원본 E2E, Tesseract main/worker/core, package-lock의 SHA-256이 일치한다.
- 인증서 검증을 그대로 둔 `/usr/bin/chromium`의 독립 fetch에서 OCR 영어 데이터 URL이 `net::ERR_CERT_AUTHORITY_INVALID` 및 `TypeError: Failed to fetch`로 실패함을 직접 확인했다. 셸 HEAD는 같은 URL에서 200이므로 브라우저 인증서 신뢰 경로 차이로 진단한다. 인증서 우회·신규 자격증명·권한 확대 없음.
- baseline 원본 OCR E2E: desktop/mobile **동일하게 2개 실패** (각 150초, `2행 1열` 미생성 timeout). 현재 변경과 기준 코드에서 동일하므로 신규 자동차 기능으로 인한 회귀가 아닌 기존 클라우드 브라우저 환경의 실패로 판단한다. `/tmp/ontools-baseline-playwright.config.ts`로 4128 로컬 서버를 사용하며 desktop/mobile 원본 테스트와 150초 assertion 제한을 유지했다.
- 후속 변경은 계산 단위 테스트 5개와 이 기록뿐이며 계산 로직/UI 변경 없음. 후속 lint/typecheck 및 전체 unit 160개 통과. build/신규 E2E는 앞서 통과한 동일 기능 코드에 대한 결과를 유지한다.
