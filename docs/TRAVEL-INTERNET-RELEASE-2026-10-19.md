# 해외여행 인터넷 비용 비교

운영 경로: https://ontools.co.kr/travel-internet

## 계산 모델

- eSIM·통신사 로밍: 동일한 개인 견적을 여행 인원 전체가 각각 구매한다. 개인별 서로 다른 요금 혼합은 범위 밖이다.
- 포켓와이파이: 여행 인원이 아닌 공용 기기 수에 요금을 곱한다. 기기당 사용 인원은 수용 인원 경고에만 사용한다.
- 패키지: 요금 × 구매 인원 또는 기기 수. 1회 구매만 반영하고 여행보다 짧은 유효기간은 경고한다. 자동 재구매/연장하지 않는다.
- 일 요금: 요금 × 사용자가 입력한 실제 과금 일수 × 인원 또는 기기 수. 여행 기간과 과금 일수는 독립적이며 다르면 경고한다.
- 추가 비용: 개인/기기당 추가 비용 × 수량 + 일행 전체 추가 비용. 배송·수령·반납·설정 등 소멸 비용을 중복 없이 입력한다. 반환되는 보증금은 소비비용에서 제외한다.
- 1인당 비용: 전체 입력 비용 ÷ 여행 인원. 최대 소수 둘째 자리 표시이며 실제 청구액과 다를 수 있다.

## 범위와 입력 보호

실시간 최저가 검색·자동 수집·자동 환율·외부 유료 API를 사용하지 않는다. 원화로 환산한 부가세 포함 최종 견적을 사용자가 입력한다. 빈 요금은 미입력이며 0과 구분한다. 금액은 0~1억 정수, 인원/기기/사용 인원은 1~100 정수, 일수는 1~365 정수로 제한한다. 계산 최대값은 안전한 정수 범위 안이다. 입력 변경 시 기존 결과를 숨긴다. 초기화하면 요금은 다시 빈값이다. 예제의 모든 수치/조건은 합성이며 실제 상품이 아니다.

데이터는 매일/전체/미확인을 구분하고 용량과 속도 등은 자유 입력한다. 데이터 용량을 자동 합산하거나 일 용량과 전체 용량을 환산하지 않는다. 개인 잔여량 자동 합산, 무제한의 고속/핫스팟 보장, 공유 가능 여부를 추정하지 않는다. 미확인을 무제한으로 취급하지 않는다. 공용 기기 수용 인원 부족, 공유 미확인, 따로 이동 제약을 명시한다. 가격만으로 상품 동등성·최저가·절감을 주장하지 않는다.

무료·가입/결제 불필요. 입력은 브라우저 상태에만 유지하고 별도 저장/전송하지 않는다. 기존 사이트 광고/분석 인프라에는 계산 입력을 보내지 않는다. 사용자 PC와 GetLuckyLab에는 접근하지 않았다.

## 등록과 검증

기존 ToolShell·도구 레지스트리·검색/홈 목록·sitemap·canonical·Open Graph·FAQ 패턴을 따른다. CI에 명시적 typecheck 단계를 추가했다. Playwright 전용 브라우저가 없는 클라우드 환경에서는 `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium`을 사용할 수 있으며 CI 기본 설치 경로는 유지한다.

로컬 검증 결과와 최종 배포 증거는 작업 보고에서 SHA별로 기록한다. 새 E2E는 합성 예제 정확 계산, 반복 실행, 입력 변경 후 결과 무효화, 유효기간 부족, 과금 일수 차이, 기기 수, 인원 부족, 빈값/음수/소수/상한 초과, 0, 초기화, canonical, 화면 넘침과 비 GET 입력 전송 없음을 데스크톱/모바일에서 검사한다.
