# 온툴즈 기능·유입 제안

## 전제

방문자는 거의 없거나 미측정, AdSense는 미승인 상태다. 아래는 검색량 조사 결과가 아니라 현재 코드와 사용자 문제에 근거한 실험 우선순위다. 유입·수익을 보장하지 않는다. 이번 변경에서는 기반 수리와 계측을 진행했으며 아래 신규 제품은 아직 구현하지 않았다.

## 먼저 만들 하나: 제출 파일 준비

사진을 올리고 제출처의 파일 형식·가로세로·최대 용량을 입력하면, 검사 → 자르기 → 크기 조정 → 압축 → 최종 규격 확인 → 다운로드까지 한 화면에서 끝낸다.

- 대상: 취업 지원, 증명서 첨부, 온라인 신청 과정에서 업로드가 거절된 사람.
- 첫 버전: JPG/PNG/WebP, 사용자 지정 px·KB, 비율 유지, 원본/결과 비교, 최종 실제 바이트 검사, 달성 불가 시 해상도 조정 선택. 문서와 인물 사진을 구분한다.
- 차별점: 이미 있는 개별 도구를 돌며 파일을 여러 번 올릴 필요가 없다. 파일 내용은 서버로 보내지 않는다.
- 검색어 가설: `사진 500KB 이하`, `413 531 사진`, `지원서 사진 업로드 오류`. 키워드마다 같은 페이지를 복제하지 않고 실제 다른 제약과 예제를 제공한다.
- 개발: 기존 리사이즈·압축·변환의 순수 함수를 먼저 공통 모듈로 추출한 뒤 하나의 작업 상태로 연결한다. Object URL 수명과 취소는 이번에 정리한 방식을 재사용한다.
- 검증: 회전된 JPG, 투명 PNG, 지나치게 작은 원본, 목표 크기 미달성, 모바일 대용량, 이름에 개인정보가 있는 파일.
- 수익 가설: 단건 무료 유지. 반복 작업 수요가 확인되면 여러 파일 일괄 처리와 사용자 프리셋 저장을 유료 후보로 검토한다. 현재 결제 도입은 보류한다.

여권 프리셋은 특히 신중해야 한다. 외교부는 온라인 사진의 형식·크기뿐 아니라 편집 제한도 정한다. 배경 제거·얼굴 보정 기능을 여권용으로 권장하지 않고, 기술 규격 통과를 접수 승인으로 표현하지 않는다. [외교부 온라인용 사진파일 안내](https://www.passport.go.kr/home/kor/contents.do?menuPos=12)

## 콘텐츠는 실패 상황 중심

- `용량을 줄였는데도 사진 업로드가 안 되는 이유`: 실제 파일 형식, 확장자, px, KB 차이를 예시 파일로 검증.
- `가린 이미지에 원본이 남아 있을까?`: 내보낸 픽셀, 메타데이터, 편집 가능한 PDF의 차이. 검은색 덮기와 약한 모자이크의 차이 설명.
- `영수증 사진 10장을 A4 PDF 하나로`: 샘플 파일, 종이 방향·여백별 실제 결과 비교.
- `무료 도구가 파일을 서버로 보내는지 확인하기`: 온툴즈의 실제 네트워크 흐름과 외부 분석·광고 요청을 구분해 공개.

AI 글 수십 개보다 검증한 도구 하나와 재현 가능한 예제 몇 개를 먼저 만든다. Google도 고유한 가치와 실제 사용자에게 도움이 되는 내용을 강조하지만, 이것이 순위 보장은 아니다. [검색 센터 가이드](https://developers.google.com/search/docs/fundamentals/creating-helpful-content?hl=ko)

## 첫 30일 운영 실험

1. Search Console 소유권·사이트맵·색인 오류와 GA4 실제 수신부터 확인한다. 아직 계정 데이터는 확인하지 않았다.
2. 제출 파일 준비 MVP 하나와 예제 가이드 3개를 만든다. 소개·문의·개인정보 문서가 실제 동작과 일치하는지 점검한다.
3. 관련 커뮤니티에 허용 규칙을 확인한 뒤 실제 문제를 해결하는 예제를 공유한다. 반복 홍보나 클릭 유도는 하지 않는다.
4. 주간으로 검색 노출, 검색어, 유입 페이지, 시작·성공·실패·다운로드, 모바일 오류, 재방문을 본다. 이번 완료 이벤트는 연봉·환율·PDF 중심이므로 신규 기능에는 시작 이벤트도 붙인다.
5. 노출 자체가 없으면 색인과 배포 경로, 유입은 있는데 완료가 적으면 UX와 오류, 완료·재방문이 생기면 일괄 처리 수요를 조사한다.

광고 승인 전에는 실제 슬롯을 만들어내거나 광고 공간을 늘리지 않는다. 승인 준비의 중심은 고유 콘텐츠, 명확한 탐색, 정상 동작이다. 수익 예상액은 실제 페이지뷰와 광고 지표가 생긴 다음 계산한다. [AdSense 사이트 준비 기준](https://support.google.com/adsense/answer/7299563?hl=ko)
