# 신규 도구 7종 구현 기록

## 기존 패턴

- 계산기: 기존 `ToolShell`, `Button`, `ToolGuide`, `FaqSection` 사용.
- 이미지: 기존 `image-resize` 페이지의 헤더, 브레드크럼, 2:1 도구/보조정보 배치, 업로드·미리보기 패턴을 `ImageWorkflowPage`로 재사용. 기존 페이지 자체는 변경하지 않음.
- `lib/tools.ts`에 등록하여 홈 카테고리, 검색, 관련 도구에 노출. 사이트맵은 기존 페이지 탐색 방식으로 자동 포함.
- 기존 Object URL 관리와 개인정보를 포함하지 않는 분석 이벤트 사용. 공통 이미지 처리, 취소, 표 내보내기만 최소한으로 분리.
- 다운로드를 가리는 기존 하단 안내 버튼은 신규 페이지에서만 숨김. 기존 도구는 기본 동작 유지.

## 경로와 제공 범위

| 경로 | 제공 범위 | 주요 제한 |
| --- | --- | --- |
| `/photo-submit` | 픽셀·KB·형식 지정, 자르기 위치/확대, 흰 여백, 실제 바이트 검증 | JPG/PNG/WebP, 출력 크기를 자동 축소하지 않음, 기관 제출 승인 보장 아님 |
| `/receipt-pdf` | 순서 변경, 검은 가림, A4 PDF | 최대 12장, 긴 변 1600px, 가림 후 픽셀만 PDF 삽입 |
| `/selling-price` | 비용 합산, 수수료·목표 마진 역산, 단위 올림, 손익분기, CSV | 수수료 직접 입력, 세금·반품·별도 배송 매출 제외 |
| `/shift-pay-calendar` | 월 달력, 하루 한 근무, 휴게 1구간, 야간·일 연장·휴일 가산, CSV | 주 40시간 초과분 직접 입력, 주휴·유급휴일 자체 임금·공제 제외, 출근일 집계 |
| `/resignation-compare` | 2~5개 후보, 실제 3개월 일수, 통상임금 하한, 연차 정산, CSV | 일반 퇴직금/DB형 단순 추정, 휴직·중간정산·DC형 제외, 연차 일수 직접 입력 |
| `/table-to-excel` | Tesseract 한국어/영어 OCR, 영역 지정, 열 경계, 셀 편집·행 추가/삭제, CSV/TSV·복사 | 최대 200행/12열, xlsx·병합 셀·복잡한 표 서식 미지원, 원본 대조 필요 |
| `/product-photo-batch` | 일괄 크기/용량/형식, 텍스트 워터마크, 사진별 오류, ZIP, 취소 | 최대 20장/원본 합계 80MB, 장당 결과 최대 2000KB |

이미지 원본은 장당 최대 20MB/4,000만 픽셀, 출력은 최대 4096px/변 및 1,600만 픽셀. 투명 영역은 흰색 처리, 애니메이션은 정지 프레임, EXIF는 복사하지 않는다. 계산·근무 기록을 새로고침 이후 보존하지 않는다.

## OCR 운영

- `npm ci`의 postinstall이 PDF 워커와 OCR 런타임/워커/라이선스를 `public`으로 복사한다. 생성된 OCR 엔진은 Git에 넣지 않는다.
- `/table-ocr.worker.js`가 독립 워커에서 검증된 Tesseract 엔진을 실행한다. 작업 취소·페이지 이탈·180초 제한 시 워커 종료. 엔진은 사이트에서, 언어 데이터는 jsDelivr의 버전 지정 패키지에서 다운로드한다.
- 사진이나 OCR 결과를 서버에 업로드하지 않는다. 언어 모델만 IndexedDB 캐시 대상이다. 개인정보처리방침에 이 네트워크/저장 동작을 반영했다.
- 내보내는 CSV/TSV는 UTF-8 BOM을 포함한다. 사용자·OCR 문자열에서 수식으로 해석될 수 있는 접두부를 문자 처리한다.

## 검증

- 순수 로직: 판매가, 밤샘/휴게/휴일 가산, 날짜·월말, 퇴직금 공식, OCR 행/열 배치, 수식 방어, 실제 용량 상한.
- Playwright: 데스크톱·모바일에서 7개 도구 사용, CSV/ZIP/사진/PDF 다운로드, PDF 가림 픽셀, 실제 OCR, 편집 후 결과 무효화, 가로 넘침 검사와 스크린샷.
- 외부 언어 모델 다운로드를 포함한 OCR 통합 테스트는 인터넷 연결이 필요하다.
- 운영 배포와 검색 유입·수익 검증은 구현/로컬 검증과 별개다. 방문자 증가를 보장하지 않는다.
